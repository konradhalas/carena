Carena

Multiplayer car arena combat. Drift, jump and blast your way through a dirt arena — up to 50 players per match.

Download Source on GitHub

What it is

Heavy cannon

Slow, punchy shells with drop. Four hits kill, every hit shoves. Twelve rounds — then go find an ammo crate.

Arcade handling

Raycast suspension buggies with handbrake drifts, jumps and berms. Flip over? Keep driving on the roof.

Online multiplayer

Server-authoritative with client-side prediction. Host a game, join a friend or run a dedicated server.

Timed matches

Kill limit or clock, kill feed, scoreboard. Repair kits and ammo crates around the arena.

Play

  1. Grab a build for Windows, macOS or Linux from the latest release, or run from source with Godot 4.7: godot --path .
    The macOS build is not notarized: if macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway.
  2. Host a game or join one by IP (UDP port 7777).
  3. Dedicated server: godot --headless -- --server
